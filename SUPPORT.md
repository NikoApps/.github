# Getting help

- **Something isn't working:** open an issue in the app's repository using the bug report form.
- **Something is hard to use with an accessibility tool:** use the accessibility issue form.
- **A question or an idea:** use the feature request or app idea form.
- **Anything private:** email hello@gopalkhadka.com.np.

Niko is run by volunteers, so replies can take a few days.
