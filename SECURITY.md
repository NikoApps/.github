# Security policy

Niko apps are built to collect nothing and to work without internet access, but bugs still happen.

## Reporting a vulnerability

Email **hello@gopalkhadka.com.np** with:

- Which app and version
- What the problem is and how to reproduce it
- What someone could do with it

Please don't open a public issue for security problems. You'll get a reply within 7 days. Once a fix is released, you'll be credited in the release notes unless you'd rather not be.

## Supported versions

Only the latest release of each app gets security fixes.
